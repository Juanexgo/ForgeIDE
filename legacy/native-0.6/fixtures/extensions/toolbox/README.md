# Forge Toolbox

Native example for API 1.0. Install the portable package or forge-extension.json. Open a small document, then run **Toolbox: Uppercase first letter** from the command palette. Review before applying.

The command receives the active UTF-8 document only when invoked. It has no filesystem, network, process or WASI imports. Its Wasm source is ../uppercase-first.wat. The theme and Rust answer snippet work immediately after installation.
